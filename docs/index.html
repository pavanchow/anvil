Anvil

A compiler backend with a readable register allocator

Most build your own compiler projects stop at the front end. Anvil is the backend. It takes an SSA intermediate representation and lowers it to a small target machine with only K physical registers, and it proves the result correct by running two interpreters and asserting they agree.
